# Project Context

## Project

Sound Continuum

## Purpose

A weekly music curation project connecting timeless classics, contemporary
music, and emerging artists through intentional musical bridges.

## Core idea

The project is about creating a continuous musical journey, not producing
disconnected weekly playlists. See [`docs/manifesto.md`](../manifesto.md).

## Editorial principles

Reference [`docs/manifesto.md`](../manifesto.md) — this is the canonical
source, not restated here.

## Important distinctions

- Sound Continuum is **not** simply a recommendation engine.
- Human editorial judgment remains responsible for the final playlist.
- Community feedback is a signal, not a voting mechanism.
- Discovery means surfacing meaningful music, not simply unknown artists.
- Musical bridges matter more than rigid genre classification.
- The project should think one or two editions ahead when useful.
